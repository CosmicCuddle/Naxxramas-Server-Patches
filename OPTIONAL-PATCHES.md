# Optional Patch History

This document is reserved for optional Naxxramas client patches.

Optional patches are not required to connect to or play on the server. They may include cosmetic changes, alternative visuals, quality-of-life client modifications or other personal-preference patches.

These will be documented separately from the required Main Server Patch set so players can clearly see what is mandatory and what is optional.

The optional patch collection will be added here as it is reviewed and organised.
